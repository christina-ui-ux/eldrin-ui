# eldrin-ui playground

Prototyping app for [Eldrin UI](../../README.md), workspace-linked to
`packages/eldrin-ui` — no publish step, edits to the library show up here
immediately.

See [`CLAUDE.md`](./CLAUDE.md) for what belongs in this app versus what
belongs back in the design system, and the `src/prototypes/` convention.

```bash
npm install        # from the repo root
npm run dev -w apps/playground
```
